## Push an existing local project to this GitHub repository

If your project already exists locally, connect it to this repository and push it with:

```bash
cd "c:\Users\zivd1\OneDrive\Desktop\AI PROJECT\safeheight"
git remote add origin https://github.com/zivd15/safeheight.git
git branch -M main
git push -u origin main
```

This repository uses `main`, so `git push -u origin master` should be replaced with `git push -u origin main`.
